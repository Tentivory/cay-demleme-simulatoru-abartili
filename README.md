# Çay Demleme Simülatörü (Abartılı Versiyon)

## Giriş

Bu yazılım, insanlık tarihinin en önemli sorunlarından birini çözmek için geliştirilmiştir: **Doğru çay demleme**.

Çay, sadece bir içecek değildir. Çay, medeniyetin ta kendisidir. Yanlış demlenmiş bir çay, toplumun ahlaki çöküşüne, trafik kazalarına ve hatta komşu kavgalarına yol açabilir. Bu simülatör, bilimsel yöntemlerle (çok ciddi bilim) çay demleme sürecini modeller.

## Özellikler

- Su sıcaklığını 0.001 derece hassasiyetle kontrol eder (gerçekte rastgele sayı üretir ama şöyle gösterilir).
- Demleme süresini abartılı şekilde uzatır çünkü acele iş şeytana uyar.
- Her adımda felsefi yorum yapar.
- Çayın acılık seviyesini ölçer ve "abi bu çay çok acı" diye bağırır.
- Milli güvenlik seviyesinde önemli uyarılar verir.

## Kullanım

```bash
python cay_demle.py
```

Program çalıştığında sabırla bekleyin. Acele etmeyin. Çay bekler.
